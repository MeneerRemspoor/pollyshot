# Pollyshot

We make many screenshots a day. In my case, I select the image to go to clipboard, then go the app of my choosing and  psate it there. If there's multiple screenshots that i need to add, the same process is repeated. What if we could optimize this flow and reduce clicks and context switching?

Pollyshot is a macOS app that lets you press a shortcut, select part of your screen, and instantly send it to another app. Fully configurable, up to 10 apps.

No copy. No paste. No friction.

The goal is to make screenshots feel like a first-class input — fast, disposable, and easy to route anywhere.

## Status

Early work in progress.  
Core functionality is being built; features and scope will evolve.
only tested with a few selected apps, such as ChatGPT, Slack, Cursor, Text Editor, Zed and Whatsapp

## Requirements

- macOS
- Screen Recording permission
- Accessibility permission

## Notes

Pollyshot is currently focused on getting the fundamentals right:
- capturing screen content
- delivering it reliably to apps
- staying out of the way

More functionality will come later.
